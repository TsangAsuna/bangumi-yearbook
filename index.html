开发者接入指南（iframe / postMessage / BGMReport API）

① iframe 嵌入（参数：uid type year source embed=1）：

<iframe src="…/report?uid=xxx&type=anime&year=all&embed=1"
        style="width:100%;height:640px;border:0;border-radius:12px"></iframe>

② 页面会向父窗口 postMessage：{event:'bgm-report-ready', data} / {event:'bgm-report-error', error}

③ 同窗口 JS 调用：BGMReport.load('用户ID', {type:'anime', year:'all'}) 返回 Promise；数据可直接读任意支持 /v0 透传 + CORS 的镜像；搭配 bgm-proxy 类反代同域部署时，/report/api?uid=&type= 聚合接口会被自动优先使用。
